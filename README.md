# Peukan Digital - Kriya Aceh

File HTML lengkap untuk antarmuka web **Peukan Digital - Kriya Aceh** sesuai dengan tampilan referensi.

## Cara Menjalankan
1. Ekstrak file ZIP ini.
2. Buka file `index.html` langsung di browser (Chrome, Edge, Firefox, atau Safari).

## Fitur yang Disertakan
- **Navigasi Sidebar & Responsif Mobile**: Beranda, Katalog, Peta, dan Dashboard Penjual.
- **Hero Section & Statistik**: Kartu unggulan *Sulam Kasab*, ringkasan statistik 9 produk dari 5 daerah & 9 pengrajin, serta kartu produk paling sering dipesan.
- **Katalog 9 Produk Kriya Lengkap**: Dilengkapi filter kategori (*Semua*, *Sulam & Kasab*, *Tenun & Songket*, *Logam & Ukir*, *Anyaman & Kayu*), filter daerah Aceh, serta pencarian real-time.
- **Modal Sejarah & Cara Membuat**: Menampilkan latar belakang budaya masing-masing kriya saat tombol diklik.
- **Integrasi Pesan WhatsApp & Peta Interaktif**: Klik daerah di peta untuk memfilter katalog berdasarkan asal daerah.
